# Guia de atualização — v2.3.0 final consolidada

Base anterior: **v2.3.0 — Etapa 2: Promoções e Eventos**  
Nova entrega: **v2.3.0 — Versão final consolidada**

## Instalação

1. Faça uma cópia de segurança da versão atualmente publicada.
2. Descompacte este pacote.
3. Publique todos os arquivos do diretório no mesmo local do Portal do Cliente.
4. Não altere o endereço do Worker em `config.js`, salvo se a infraestrutura oficial tiver mudado.
5. Após publicar, use `Ctrl + F5` no navegador.
6. Entre no Portal e confira a prévia antes de solicitar publicação.

## Banco de dados

Não é necessária migração SQL. A evolução utiliza o mesmo rascunho persistido no Worker/D1.

## Verificação recomendada após instalar

- abrir Podcasts, Vídeos, Promoções e Eventos;
- visualizar um conteúdo salvo de cada módulo;
- abrir a prévia em desktop, tablet e celular;
- testar as listas completas;
- salvar o rascunho;
- confirmar que a programação só indica **AGORA** no horário correto.
