# Atualização para v3.0.0 — Etapa 1

## Repositório correto

`CentralRádiosBrasil-Portal-Cliente`

## Procedimento

1. Faça backup da v2.6.0 Final Consolidada.
2. Descompacte o pacote.
3. Envie o conteúdo interno para a raiz do repositório do Portal do Cliente.
4. Não envie o ZIP fechado.
5. Não altere Worker, D1, Portal Público/PWA ou Admin.
6. Aguarde o GitHub Pages concluir a implantação.
7. Pressione `Ctrl + F5`.
8. Abra **Pré-produção** no menu.

## Retorno

Se houver falha inesperada, restaure os arquivos da v2.6.0 Final Consolidada no mesmo repositório. Nenhum rollback de Worker ou banco é necessário porque esta etapa não os modifica.
