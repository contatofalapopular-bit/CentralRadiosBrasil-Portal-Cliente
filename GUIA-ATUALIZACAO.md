# Atualização para o Portal do Cliente v2.2.0

## Compatibilidade

- Worker: v1.15.0
- Admin Central: v3.10.0
- Banco: D1 atual
- Migração SQL: não necessária

## Publicação

1. Faça uma cópia do repositório `CentralRadiosBrasil-Portal-Cliente`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Substitua os arquivos existentes.
4. Use o commit: `Portal do Cliente v2.2.0 — Etapa 2 editorial e temas`.
5. Aguarde o GitHub Pages concluir.
6. Abra o Portal e pressione `Ctrl + F5`.

## Testes recomendados

1. Programação: criar um programa em vários dias e testar um conflito de horário.
2. Locutores: cadastrar um locutor, definir ordem e vinculá-lo a um programa.
3. Notícias: criar rascunho, notícia agendada e notícia publicada.
4. Temas: visualizar os seis modelos e confirmar que o conteúdo é o mesmo.
5. Salvar rascunho, atualizar a página e verificar a persistência.

## Observação

O tema Morada manteve sua estrutura. Os outros temas receberam composições próprias, com mudanças reais de posição, hierarquia, cores e apresentação.
