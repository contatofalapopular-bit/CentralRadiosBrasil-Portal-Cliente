# Atualização para o Portal do Cliente v1.1.0

1. Abra o repositório `CentralRadiosBrasil-Portal-Cliente`.
2. Envie os seis arquivos desta pasta para a raiz do repositório.
3. Confirme a substituição de `index.html`, `app.js`, `config.js`, `styles.css`, `manifest.webmanifest` e `README.md`.
4. Use a mensagem de commit:

   `Portal do Cliente v1.1.0 — Painel avançado de edição do site`

5. Aguarde o GitHub Pages concluir a implantação.
6. Abra o Portal e pressione `Ctrl + F5`.

## Teste rápido

- entre com o acesso já criado;
- abra `Gerenciar site`;
- confirme o menu lateral com Configurações, Layout, Módulos, Conteúdo, Extras e Publicação;
- altere um campo de teste;
- salve o rascunho;
- abra a prévia;
- confirme o novo número no histórico de versões.

Não é necessário atualizar o Worker 1.14.2 nem o Admin 3.10.0 para esta entrega.
